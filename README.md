# 🤖 Basic Chatbot Game

A simple, interactive chatbot project developed using Python. This project demonstrates basic chatbot conversations and Python programming concepts.

## 📌 Project Overview

The **Basic Chatbot Game** is a beginner-friendly Python project that allows users to interact with a chatbot through text-based conversations. It is designed to practice fundamental programming concepts and understand how conversational programs work.

## ✨ Features

- 💬 Text-based chatbot interaction
- 🐍 Developed using Python
- 🎮 Simple and beginner-friendly
- 🧠 Demonstrates basic programming and conversation logic
- 🖥️ Runs in the terminal or command prompt

## 🛠️ Technologies Used

- **Language:** Python
- **Interface:** Command Line Interface (CLI)
- **Tools:** Any Python-compatible editor, such as VS Code

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Kashish-s123/Basic-Chatbot-game.git
```

### 2. Open the Project Folder

```bash
cd Basic-Chatbot-game
```

### 3. Run the Python Program

Make sure Python is installed, then execute:

```bash
python Basic_Chatbot.py
```

If your system uses the `python3` command, run:

```bash
python3 Basic_Chatbot.py
```
